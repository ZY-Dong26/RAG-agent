# 开发辅助实现

本目录与 `src/rag_agent/` 并列，核心 RAG 不依赖本目录。
所有手动运行入口统一位于项目根目录下的 `scripts/`。

```text
devtools/
```

## 批量评测与指标口径

生成回答只接收问题和检索证据，不接收 ground_truth、eval_criteria 或 reference_context_ids。
默认串行执行，模型与索引只加载一次；84题会产生相应的回答模型调用，没有额外的评分模型调用。

每次结果包含：

- `items/`：逐题原子保存的记录，恢复时的依据。
- `results.jsonl`：每题完整答案、检索片段、实际发送提示词、耗时及接口返回用量。
- `results.csv`：Excel 可直接打开，含“人工评分”和“人工备注”空列。
- `report.md`：问题、参考答案、实际回答、评分标准及检索证据，方便人工阅读。
- `summary.json`：整体、按题型、按难度汇总指标。
- `run.json`：数据集、映射、索引文件、代码和模型参数快照，不含密钥。

指标的口径：

- Hit@K：前 K 个片段是否命中任一目标文档。
- Recall@K：前 K 个片段覆盖的不同目标文档数 / 标注的不同目标文档数。
- MRR@K：第一条目标文档片段排名的倒数，再对有标注且检索完成的题目求平均。
- 没有目标文档标注时指标为 null；目标文档尚未入库时另行标记，仍保留在检索指标中。
- 检索完成但生成失败的题仍参与检索指标；回答成功率仅表示成功取得非空回答，不代表回答正确。
- 记录检索、生成、单题总耗时，平均值及最近秩 P50/P95；不包含模型初始化耗时。
- Token 仅统计接口返回的 usage；缺失值保留 null，中断及失败请求可能产生未被记录的费用。

检索指标是文档级，不证明找到了正确段落；不自动计算答案正确率或忠实性分数。
中断后已保存题目可恢复，正在进行但未保存的题目会重做。索引、源代码或配置发生变化时拒绝混跑，
请换输出目录。恢复/重试会重新导出 CSV 和 Markdown，人工评阅前建议等批次结束，或另存副本。
评测结果包含本地资料和回答，默认被 Git 忽略。

评测实现的逻辑快照键保留路径迁移兼容，迁移另有清单留档；实际代码或索引变化仍会拒绝混跑。
